# 家庭成长站第一期实施计划

本次完成本地可运行应用、测试与 Docker 交付，随后按部署前检查条件部署现有 Oracle；不得影响代理。

## objective

- 实现金钱和积分事件、共同确认及协议月统一入账的家庭服务。

## scope

- 不实现商品商城、用户管理页面、在线规则发布或自动任务；试卷跳过本期包含。

## steps

- WP01：账号与首次设置。账号密码哈希、数据库会话、管理员全局和本人权限；首次管理员设置周期锚点，正式帐号钱包从零开始。
- WP02：周期与奖惩规则。纯函数实现协议月、分档、家务限制、哭泣候选、两个独立封顶、积分跳过及反向抵销。
- WP03：事件与统一入账。只追加事件与确认，纠错使用反向记录，月底待办、总结快照、对象本人及任意管理员确认（创建即确认）、负钱包及跨期差额原子入账。
- WP04：响应式界面与容器。实现手机与电脑完整登录、记录、确认、结算、历史与协议；固定依赖、Docker构建、手动备份恢复，商城无入口。

- 管理员新增记录类型对应金额和积分，每次记录只保存次数、时间与原因，月底统一计算。

## interfaces

- 输入发生时间、原因、依据和次数，不输入金额或操作人；管理员全局，普通用户本人。

## work_packages

- WP01 提供 artifact:auth，由依赖单元消费。
- WP02 提供 artifact:domain，由依赖单元消费。
- WP03 提供 artifact:ledger，由依赖单元消费。
- WP04 提供 artifact:application，由依赖单元消费。

## test_matrix

- 先写行为测试观察 RED；覆盖边界、非法输入、权限、重复、并发和事务中途失败。

## verification

- 执行 npm test、npm run typecheck、npm run build、npm run test:e2e；验证容器、备份恢复和上线前后代理。

## done_criteria

- 交付已验证代码、运维命令和证据，不把本地通过或容器 Up 当成远程上线通过。

## stop_conditions

- 试卷跳过只使用足够的已结算积分；未授权的破坏性部署与 OCI 变更禁止。

## external_sources

- 依据现有产品设计0.6、开发设计0.4、Q01至Q13决策和官方Next.js、Prisma7、SQLite文档实现。
